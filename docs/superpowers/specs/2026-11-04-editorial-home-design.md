# 首页与功能实录设计

用户于 2026-11-04 确认本地第三版草图方向。实现该版杂志式首页和真实浏览器操作示例。

## 页面与内容

- 首页保留最新一期为主稿，直接展示标题、简短摘要、日期和阅读入口，不再嵌入整期正文。
- 主稿旁展示真实站内查询录屏。下方为当期三条短讯、近期型号和 Computer use 概念入口。
- 首页随最新已发布周报变化。短讯与精选型号写在该期 frontmatter，缺省时使用当期 highlights 和最新模型记录，不能继续显示上期短讯。
- 新增 `/capabilities` 页面，提供网页操作、电脑操作两个可链接的分区，桌面与手机均可访问。
- 网页操作区展示 2026-11-02 录制的 Codex 查询 Kimi 记录样片：7 秒节选与约 64 秒完整片段、任务、查到的答案、执行入口和工具方式。
- 明确样片通过网页结构定位控件；不指定未核定的底层型号，不将其当作模型横评或纯截图式桌面测试。说明首次录制中断后重录、节选压缩等待。
- 电脑操作区列出已于 2026-11-02 核查的 Terra、Gemini 3.8 Flash、Claude Opus 5.5 文档示例，附入口、运行环境与官方来源。不是完整名单或实测排名。

## 视觉与交互

- 首页和功能页使用纸色背景、深色文字、细分隔线、Emergence 字标；沿用已确认草图的字号、栏宽和主次关系。
- 阅读正文、模型目录等既有页面保持原有内容与阅读样式，新入口进入全站导航。
- 原生 video controls，默认不自动播放、不预下载完整视频；按需播放与切换完整片段。
- 键盘能切换分区、操作视频；移动端不出现整页横向溢出，模型对照表可在容器内横向滚动。
- 保留原有 canonical、RSS、sitemap、文章 URL 和 GitHub Pages 子路径支持。

## 验收与发布

`npm run check` 与根路径/`/ai-weekly/` 两种构建通过。浏览器验证首页、分区深链、键盘操作、视频播放/切换、移动布局与已有文章链接。审查差异后合入 main，由现有 GitHub/EdgeOne 流程发布，核对线上 HTML 与视频资源。
