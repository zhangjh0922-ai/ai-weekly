# Concept Guide Implementation Plan

> **For agentic workers:** Use the current task's parallel content research and sequential implementation; review each content group before verification.

**Goal:** 让读者从周报进入陌生术语的中文解释页，并能搜索和浏览全部概念。

**Architecture:** 延用 Astro 静态内容集合，新增 `concepts` Markdown 集合、概念列表与详情页。通过明确的 `concept:slug` Markdown 链接连接正文与概念页，构建时验证目标并补齐部署子路径；不自动替换普通文字。复用既有排版、色彩和搜索模式，不新增后端。为配置 Astro 7 原生 Markdown 插件，将原有间接依赖 `@astrojs/markdown-satteri@0.4.0` 显式声明为直接依赖，保持现有渲染器和版本。

**Tech Stack:** Astro、TypeScript、Markdown、Node.js 内置测试。

## 内容与页面约定

- 第一批 12 个词条：AGI、FrontierMath、ARC-AGI、评测基准、token、上下文窗口、MoE、开放权重、智能体、computer use、提示词注入、pass@k。
- 每篇含标题、英文名、别名、分类、一句话解释、更新日期、已查阅的原始来源、相关词条，以及约 350–600 字中文解释。
- `/concepts` 展示所有词条，可按中文名、英文名、别名、解释和分类搜索筛选。
- `/concepts/[slug]` 展示正文、来源、相关概念和引用该概念的已发布周报。
- 导航新增“概念指南”。周报正文的首次关键提及用 `[词语](concept:slug)` 标注；页面标题、直接引语和来源链接保持原样。
- 词条不陈列当前模型排名，不沿用周报中未经本次核验的分数；争议定义、测试版本和能力边界须说明。
